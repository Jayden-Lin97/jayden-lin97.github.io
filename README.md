# Mind Resonance Studio

A standalone, English-language studio introduction for GitHub Pages.

## Preview

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Open `http://127.0.0.1:4173`.

## Publish

Publish the `main` branch at the repository root using GitHub Pages. The site is
buildless and uses relative asset paths, so it also works under a project URL.

Only the studio introduction is included. There are no product listings,
contact details, support pages, analytics, or external assets.
